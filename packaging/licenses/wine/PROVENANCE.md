# `COPYING.LIB` — provenance (compliance checklist B1.1)

`COPYING.LIB` in this directory is the **verbatim** text of the GNU Lesser
General Public License, version 2.1, which is the licence Wine's own
`COPYING.LIB` carries. It is shipped, not linked, because LGPL-2.1 §6 requires
supplying a copy of the licence with a binary distribution.

**Why the FSF copy rather than one lifted from the Wine tree.** LGPL-2.1 is a
single canonical document — Wine's `COPYING.LIB` is that text, unmodified, as
every LGPL project's is. The pinned WineHQ `.deb` set exemu tests against
(`example_exe/wine-dlls/`, git-ignored) ships its `usr/share/doc/wine-stable-*`
entry as a symlink and carries no licence file of its own, so there is nothing
in the artifact to copy from. Taking the text from the FSF is therefore both
the most authoritative source and a reproducible one: the URL and hash above
are enough for anyone to re-verify it byte for byte.

**Do not edit this file.** Paraphrasing, reformatting or truncating it would
break the obligation it exists to satisfy. If it is ever refreshed, re-record
the hash above in the same commit.

**Related obligations** (see `docs/COMPLIANCE.md` Part B):

- **B1.2** — Wine is **LGPL-2.1-or-later**, not "LGPL-2.1". The "or later"
  clause is part of the grant; a downstream redistributor may elect LGPL-3.0
  terms. Record it that way rather than flattening it.
- **B1.3** — the text must be reachable **without running the product**:
  `Contents/Resources/licenses/wine/COPYING.LIB` inside the `.app` bundle, and
  at the root of the release archive.
- **B2** — copyright notices, and **B3** — the written offer for source.

The invariant that makes all of this satisfiable: Wine's DLLs are shipped as
**separate loadable guest image files**, never statically linked into or
transcribed from exemu's own binaries. That claim is checked mechanically by
the separability check in CI (see `docs/COMPLIANCE.md` Part A), not asserted.
